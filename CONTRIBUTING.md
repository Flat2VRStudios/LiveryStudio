# Contributing

Edits, forks and reuse are welcome under the [MIT License](LICENSE). Contributions must be your own work or carry compatible permission. Keep third-party notices intact. Do not submit proprietary game source, SDKs, credentials, game saves, account information or local build logs.

Start with [build and test](docs/build.md). Use a focused branch and describe the user-visible problem, relevant checks and remaining game-validation limits. Add a regression for a meaningful bug or safety boundary. Keep generated outputs in ignored artifact folders. Changes to imports, restoration, portable files and publishing must preserve user data.

Submitted changes to the original editor code use the MIT License. Existing third-party components retain their own licenses.
